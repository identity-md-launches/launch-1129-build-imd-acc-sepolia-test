How points work

      
    
        
  • Every Stacked(project, trader, imd, shares) event from the Stacker is read from the chain in block chunks.
    •

    • 
        
  • Everything else is shown as direct, no points. It still stacks real tsIMD to the trader.
    • 
        
  • Leaderboards only count listed projects.
